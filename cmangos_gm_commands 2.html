Personnage & Niveau
.levelup [n]
Augmente le niveau de la cible de n niveaux
.character level [nom] [n]
Définit le niveau exact d'un personnage (en ligne ou hors ligne)
.reset level [nom]
Réinitialise le niveau à 1 (stats et talents inclus)
.reset talents [nom]
Réinitialise tous les talents (spec actuelle) du personnage ou de son pet
.reset specs [nom]
Supprime tous les talents des deux specs
.reset spells [nom]
Supprime tous les sorts non-originaux du grimoire
.reset stats [nom]
Recalcule toutes les stats au niveau actuel
.reset honor [nom]
Réinitialise toutes les données d'honneur du personnage
.maxskill
Monte toutes les compétences au maximum pour le niveau actuel
.save
Sauvegarde le personnage actuel
.saveall
Sauvegarde tous les personnages en ligne
.character rename [nom]
Marque le personnage pour renommage à la prochaine connexion
.character customize [nom]
Marque le personnage pour personnalisation à la prochaine connexion
.repairitems
Répare tous les objets du personnage ciblé
.pinfo [nom]
Affiche les informations de compte du joueur ciblé
.guid
Affiche le GUID de la cible sélectionnée
.distance [nom]
Affiche la distance entre vous et la cible / le joueur nommé
.gps [nom]
Affiche coordonnées X/Y/Z, orientation, map ID et zone ID de la cible
Objets & Sorts
.additem [ID]
Ajoute un objet à la cible (le lien chat fonctionne aussi)
.additem [ID] [n]
Ajoute n exemplaires de l'objet
.additemset [ID]
Ajoute un set complet d'équipement
.lookup item [nom]
Recherche un objet par nom (anglais) et retourne ses IDs
.lookup itemset [nom]
Recherche un set d'objets par nom
.lookup spell [nom]
Recherche un sort par nom et retourne ses IDs
.lookup skill [nom]
Recherche une compétence par nom
.lookup quest [nom]
Recherche une quête par nom et retourne ses IDs
.lookup creature [nom]
Recherche une créature par nom
.lookup object [nom]
Recherche un objet du monde (gameobject) par nom
.lookup faction [nom]
Recherche une faction par nom et retourne son ID
.lookup area [nom]
Recherche une zone par nom et retourne son ID
.lookup tele [nom]
Recherche un lieu de téléportation disponible
.lookup taxinode [nom]
Recherche un nœud de taxi par nom
.lookup title [nom]
Recherche un titre par nom et retourne son ID
.learn [ID]
Apprend le sort associé à cet ID
.learn [ID] all
Apprend toutes les rangs du sort
.learn all
Apprend un large ensemble de sorts utiles (admin)
.learn all_crafts
Apprend toutes les professions et recettes
.learn all_default [nom]
Apprend tous les sorts de départ race/classe + récompenses de quêtes
.learn all_gm
Apprend tous les sorts par défaut pour les GMs
.learn all_lang
Apprend toutes les langues
.learn all_myclass
Apprend tous les sorts et talents disponibles pour sa classe
.learn all_myspells
Apprend tous les sorts (hors talents) disponibles pour sa classe
.learn all_mytalents
Apprend tous les talents disponibles pour sa classe
.learn all_recipes [profession]
Apprend toutes les recettes d'une profession et monte le skill au max
.unlearn [ID]
Désapprend le sort (ajouter "all" pour tous les rangs)
.list talents
Affiche la liste de tous les talents connus du personnage
Quêtes
.quest add [ID]
Ajoute la quête au journal du personnage
.quest complete [ID]
Marque tous les objectifs comme complétés (lien chat OK)
.quest remove [ID]
Retire la quête du journal (état non-complété, non-actif)
Guildes
.guild create [leader] "[nom]"
Crée une guilde avec le joueur ciblé/nommé comme leader
.guild delete "[nom]"
Supprime la guilde
.guild invite [joueur] "[guilde]"
Invite un joueur dans une guilde
.guild uninvite [joueur]
Retire un joueur de sa guilde
.guild rank [joueur] [rang]
Définit le rang du joueur dans la guilde
Titres & Honneur
.titles add [ID]
Ajoute un titre à la liste des titres connus
.titles current [ID]
Définit le titre actif du joueur
.titles remove [ID]
Retire un titre de la liste
.honor add [montant]
Ajoute un montant d'honneur (gains du jour) au joueur
.honor addkill
Ajoute l'unité ciblée comme kill PvP du jour
.flusharenapoints
Distribue les points d'arène selon les classements et commence une nouvelle semaine
Instances
.instance listbinds
Liste tous les locks d'instance du joueur ciblé
.instance unbind all
Supprime tous les locks d'instance du joueur ciblé
.instance unbind [mapid]
Supprime uniquement le lock de la map spécifiée
.instance stats
Affiche des statistiques sur les instances actives
Divers
.npc info
Affiche toutes les infos du NPC ciblé (GUID, faction, entry, flags…)

Envoie une annonce serveur visible de tous, avec votre nom

Envoie un message global à tous les joueurs en ligne (chat log)

Envoie un mail à un joueur

Envoie de l'argent par mail à un joueur

.tele [nom]
Téléporte vers un lieu nommé (nom en anglais)

Téléporte le joueur ciblé et tout son groupe vers un lieu

Enregistre votre position actuelle comme destination de .tele
.tele del [nom]
Supprime une destination de la liste .tele
.lookup tele [nom]
Recherche une destination de téléportation par nom
.recall [nom]

.groupgo [nom]
Téléporte le joueur et tout son groupe vers vous

.go xy [x] [y] [mapid]
Téléporte vers les coordonnées X/Y (sol/eau) sur la map spécifiée ou actuelle
.go xyz [x] [y] [z] [mapid]
Téléporte vers les coordonnées X/Y/Z exactes
.go zonexy [x] [y] [zone]
Téléporte vers des coordonnées client dans une zone
.go grid [gridX] [gridY] [mapid]

Téléporte vers une créature via son GUID, son nom ou son entry ID
.go object [GUID|nom|id #id]
Téléporte vers un gameobject via son GUID, son nom ou son entry ID
.go graveyard [id]
Téléporte vers un cimetière par son ID
.go taxinode [id]
Téléporte vers un nœud de taxi par son ID
.go trigger [id]
Téléporte vers un areatrigger par son ID
Mode GM
.gm on / .gm off
Active ou désactive le mode GM (invisibilité aux monstres)
.gm chat on / off
Affiche ou masque le symbole Blizzard devant votre nom en chat
.gm fly on / off
Active ou désactive la capacité de vol pour la cible
.gm visible on / off
Rend le GM visible ou invisible pour les autres joueurs
.gm ingame
Affiche la liste des GMs actuellement connectés en jeu
.gm list
Affiche tous les comptes GM et leurs niveaux de sécurité
.gm setview
Active la vue à la première personne sur l'unité sélectionnée
.whispers on / off
Active/désactive la réception de chuchotements de joueurs
Combat
.the
Tue la cible instantanément
.damage [n] [école] [spellid]
Inflige n dégâts à la cible (école et sort optionnels)
.revive
Ressuscite le joueur ciblé (ou soi-même si aucun)
.respawn
Fait réapparaître la créature ciblée (ou les plus proches)
.combatstop [nom]
Arrête le combat du personnage ciblé ou du joueur nommé
.cooldown [spellid]
Supprime tous les cooldowns (ou celui du sort spécifié)
.aura [spellid]
Ajoute l'aura du sort à l'unité ciblée
.unaura [spellid]
Retire l'aura du sort de l'unité ciblée
.cast [spellid] [triggered]
Lance le sort sur la cible (triggered = sans animation/coût)
.cast back [spellid]
La cible lance le sort sur vous
.cast self [spellid]
La cible lance le sort sur elle-même
.cast target [spellid]
La cible lance le sort sur sa propre victime

Révèle la zone spécifiée sur la carte du personnage ciblé
.hidearea [areaid]

Créatures — Spawn & Gestion

.npc move [guid]
Déplace le point de spawn de la créature ciblée à votre position
.npc changelevel [n]
Change le niveau de la créature ciblée (1–63)
.npc factionid [id]
Change la faction de la créature ciblée
.npc flag [flag]
Définit les NPC flags de la créature (et de son template)

Change le modèle visuel de la créature ciblée

.npc spawndist [dist]

.npc spawntime [time]

.npc setphase [phasemask]
Change le phasemask de l'unité ciblée (sauvegardé en DB pour les créatures)
.npc tame
Apprivoise la créature ciblée (doit être apprivoisable, sans pet actuel)
.npc aiinfo
Affiche les informations IA et script de la créature ciblée
.npc info
Affiche toutes les infos détaillées du NPC ciblé

.npc textemote [emoteid]
