## English

GMRef is an in-game reference of the GM commands for cMaNGOS private servers. This version is written for Vanilla (1.12) clients and also runs on TBC (2.4.3) and WotLK (3.3.5). Browse the commands by category, search them, and click one to run it. For your own server or a server where you have GM rights.

The addon's interface is in French.

### Features

- **216 commands in 8 categories:** character and level, items and spells, quests and guilds, teleport, combat and GM mode, modifiers, NPCs and world, account and server.
- **Search:** find a command by name or description.
- **One-click run:** click a command to run it. When it needs values (a name, a number), a small window asks for them first.
- **Reputations:** max out or reset 49 factions in one click.
- **Professions:** learn any of the 14 professions in one click.
- **Macros:** ready-made command sequences you run with a single button.

### Installation

Copy the files into `Interface\AddOns` in a folder named `GMRef`, then restart the game or reload your interface.

### Commands

| Command | What it does |
|---|---|
| `/gmref` | Open or close the window |
| `/gmref on` / `/gmref off` | Turn GM mode on or off |
| `/gmref fly` | Turn GM flying on |
| `/gmref level N` | Gain N levels |
| `/gmref maxskill` | Max out your skills |
| `/gmref help` | List these commands |

Playing on TBC or WotLK only? See [GMREF for TBC / WotLK](https://github.com/EfkaBz/GMREF---All-GM-commands).

## Français

GMRef est une référence en jeu des commandes MJ pour les serveurs privés cMaNGOS. Cette version est écrite pour les clients Vanilla (1.12) et fonctionne aussi sur TBC (2.4.3) et WotLK (3.3.5). Parcourez les commandes par catégorie, cherchez-les et cliquez pour les lancer. Pour votre propre serveur ou un serveur où vous avez les droits MJ.

### Fonctionnalités

- **216 commandes en 8 catégories :** personnage et niveau, objets et sorts, quêtes et guildes, téléportation, combat et mode MJ, modificateurs, PNJ et monde, compte et serveur.
- **Recherche :** trouvez une commande par son nom ou sa description.
- **Lancement en un clic :** cliquez sur une commande pour la lancer. Si elle demande des valeurs (un nom, un nombre), une petite fenêtre vous les demande d'abord.
- **Réputations :** passez 49 factions à exalté ou à neutre en un clic.
- **Métiers :** apprenez l'un des 14 métiers en un clic.
- **Macros :** des suites de commandes toutes prêtes, lancées avec un seul bouton.

### Installation

Copiez les fichiers dans `Interface\AddOns` dans un dossier nommé `GMRef`, puis relancez le jeu ou rechargez l'interface.

### Commandes

| Commande | Effet |
|---|---|
| `/gmref` | Ouvrir ou fermer la fenêtre |
| `/gmref on` / `/gmref off` | Activer ou désactiver le mode MJ |
| `/gmref fly` | Activer le vol MJ |
| `/gmref level N` | Gagner N niveaux |
| `/gmref maxskill` | Monter vos compétences au maximum |
| `/gmref help` | Lister ces commandes |

Vous jouez uniquement sur TBC ou WotLK ? Voir [GMREF pour TBC / WotLK](https://github.com/EfkaBz/GMREF---All-GM-commands).
